12.2 Prim’s Algorithm

Prim’s algorithm is a classic algorithm used in computer science to find a minimum spanning tree (MST) for a weighted undirected graph. A minimum spanning tree is a subset of the edges of the graph that connects all the vertices together, without any cycles, and with the minimum possible total edge weight. Here’s a step-by-step explanation of how Prim’s algorithm works:

12.2.1 Steps of Prim’s Algorithm

  1. Initialization:
    • Start with a graph ( G = (V, E) ), where ( V ) is the set of vertices and ( E ) is the set of edges.
    • Choose an arbitrary vertex ( u ) from ( V ) to start the MST. Initialize a set ( T ) to keep track of vertices included in the MST, starting with ( { u } ).
  2. Priority Queue:
    • Use a priority queue (or a min-heap) to keep track of the edges with the smallest weight. Initially, insert all edges that are connected to the starting vertex ( u ) into the priority queue.
  3. Main Loop:
    • While the set ( T ) does not contain all the vertices in ( V ):
      1. Extract the edge with the minimum weight from the priority queue.
      2. Let this edge be ( (u, v) ), where ( u ) is in ( T ) and ( v ) is not.
      3. Add vertex ( v ) to the set ( T ).
      4. Add the edge ( (u, v) ) to the MST.
      5. Insert all edges connected to vertex ( v ) into the priority queue, where the other vertex of the edge is not yet in ( T ).
  4. Termination:
    • The algorithm terminates when all vertices are included in the set ( T ).

The result is a minimum spanning tree of the graph.

import java.util.*;

class Prim {
    // Edge class to store information about graph edges
    static class Edge implements Comparable<Edge> {
        int vertex;
        int weight;

        Edge(int vertex, int weight) {
            this.vertex = vertex;
            this.weight = weight;
        }

        public int compareTo(Edge other) {
            return this.weight - other.weight;
        }
    }

    // Function to run Prim's algorithm and find the MST
    public static void primMST(List<List<Edge>> graph) {
        int V = graph.size();
        boolean[] inMST = new boolean[V];
        PriorityQueue<Edge> pq = new PriorityQueue<>();
        int[] key = new int[V];
        int[] parent = new int[V];

        // Initialize keys and parent arrays
        Arrays.fill(key, Integer.MAX_VALUE);
        Arrays.fill(parent, -1);

        // Start with vertex 0
        key[0] = 0;
        pq.add(new Edge(0, 0));

        while (!pq.isEmpty()) {
            int u = pq.poll().vertex;
            inMST[u] = true;

            // Loop through all adjacent vertices of u
            for (Edge edge : graph.get(u)) {
                int v = edge.vertex;
                int weight = edge.weight;

                // If v is not in MST and weight of (u, v) is smaller than the current key of v
                if (!inMST[v] && weight < key[v]) {
                    key[v] = weight;
                    pq.add(new Edge(v, key[v]));
                    parent[v] = u;
                }
            }
        }

        // Print the edges in the MST
        for (int i = 1; i < V; i++) {
            System.out.println(parent[i] + " - " + i);
        }
    }

    public static void main(String[] args) {
        int V = 4;
        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < V; i++) {
            graph.add(new ArrayList<>());
        }

        // Add edges to the graph
        graph.get(0).add(new Edge(1, 2));
        graph.get(0).add(new Edge(2, 3));
        graph.get(0).add(new Edge(3, 1));
        graph.get(1).add(new Edge(0, 2));
        graph.get(1).add(new Edge(3, 4));
        graph.get(2).add(new Edge(0, 3));
        graph.get(2).add(new Edge(3, 5));
        graph.get(3).add(new Edge(0, 1));
        graph.get(3).add(new Edge(1, 4));
        graph.get(3).add(new Edge(2, 5));

        // Run Prim's algorithm
        primMST(graph);
    }
}

12.3 Kruskal

Kruskal’s algorithm is a popular algorithm used to find the Minimum Spanning Tree (MST) of a graph. The MST is a subset of the edges of a connected, weighted, undirected graph that connects all the vertices together without any cycles and with the minimum possible total edge weight. Here is a step-by-step explanation of Kruskal’s algorithm:

  1. Sort all the edges in the graph in non-decreasing order of their weights.

  2. Initialize the MST as an empty set. This set will store the edges that are part of the MST.

  3. Initialize a disjoint-set (union-find) data structure. This helps to manage and detect cycles in the graph as edges are added to the MST. Each vertex starts as its own set.

  4. Iterate through the sorted edges:

    • For each edge, check if the vertices of the edge belong to different sets using the union-find structure. This check ensures that adding the edge won’t form a cycle.
    • If they belong to different sets, add the edge to the MST and union the sets of the two vertices.

  5. Repeat step 4 until the MST contains exactly ( V-1 ) edges (where ( V ) is the number of vertices in the graph).

class Solution {
    public int minCostConnectPoints(int[][] points) {
        int n = points.length;
        if (n < 2) return 0;
        
        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                edges.add(new Edge(i, j, calDist(points, i, j)));
            }
        }
        edges.sort((a, b) -> Integer.compare(a.dist, b.dist));

        // union find
        Map<Integer, Node> map = new HashMap<>();
        for (int i = 0; i < n; i++) {
            map.put(i, new Node());
        }
        UnionFind uf = new UnionFind();

        int res = 0;
        Set<Edge> mst = new HashSet<>();
        Edge e = edges.get(0);
        mst.add(e);
        res += e.dist;
        uf.union(map.get(e.start), map.get(e.end));

        int idx = 1;
        while (mst.size() != n - 1) {
            while (idx < edges.size()) {
                e = edges.get(idx);
                boolean success = uf.union(map.get(e.start), map.get(e.end));
                if (success) {
                    mst.add(e);
                    res += e.dist;
                    break;
                } else {
                    idx++;
                }
            }
        }

        return res;
    }

    public int calDist(int[][] points, int i, int j) {
        return Math.abs(points[i][0] - points[j][0]) + Math.abs(points[i][1] - points[j][1]);
    }

    public class Edge {
        public int start;
        public int end;
        public int dist;

        public Edge(int s, int e, int d) {
            this.start = s;
            this.end = e;
            this.dist = d;
        }
    }

    public class Node {
        public Node parent;
        public int rank;

        public Node() {
            this.parent = this;
            this.rank = 0;
        }
    }

    public class UnionFind {
        public boolean union(Node x, Node y) {
            Node rx = find(x), ry = find(y);
            if (rx == ry) return false;

            if (rx.rank > ry.rank) {
                ry.parent = rx;
            } else if (rx.rank < ry.rank) {
                rx.parent = ry;
            } else {
                ry.parent = rx;
                rx.rank++;
            }
            return true;
        }

        public Node find(Node node) {
            while (node != node.parent) {
                node = node.parent;
            }
            return node;
        }
    }
}
